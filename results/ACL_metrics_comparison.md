### Methodology

- **Policy Recall / Precision**: Measured against expert-annotated reference policies per document. Matching uses domain + Jaccard similarity (threshold 0.30) on description tokens.
- **Condition F1**: Micro-averaged over condition triples (type, parameter, operator) compared to reference conditions.
- **Conflict F1**: Set-based F1 over detected conflict pairs vs. reference conflicts.
- **Compliance %**: Fraction of enforcement decisions matching expected action on 8-scenario test set (see `eval/reference_data/enforcement_gt.json`).
- **FP %**: False positive rate — escalated when should have passed.
- **Latency**: Average wall-clock seconds per enforcement decision.
